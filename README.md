
<h3> Units </h3>

- Mass: N*s^2/mm = 1000kg = 1Mg = Tonnes
- Pressure: MPa = N/mm^2
- Length: mm
- Force: N
- Time: s
- Power: mW
- Current: mA 
- Energy: mJ
